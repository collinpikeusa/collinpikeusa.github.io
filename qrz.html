QRZ bio builder

This page generates a self-contained HTML biography for QRZ.com — styled entirely with inline attributes so it survives QRZ’s sanitiser, and rendered identically whether a visitor is using QRZ’s light or dark theme. The Parks on the Air numbers are pulled live, so you can come back any time, copy, and paste to refresh your profile.

How to use it

  1. Hit Copy HTML below.
  2. Sign in to QRZ and open My Account → Edit Bio for WE4RR.
  3. Switch the editor into HTML / source mode (the </> button).
  4. Select everything already there, delete it, and paste.
  5. Save, then view your profile to confirm.

Worth knowing

  1. QRZ strips <script> and external stylesheets — this template uses neither, so nothing will be lost.
  2. Numbers are frozen at paste time. QRZ cannot fetch live data; revisit this page and re-paste to update.
  3. To add your QSL card photo, upload it through QRZ’s own image tool and drop it in after pasting.
  4. Keep a copy of your old bio before overwriting it.
